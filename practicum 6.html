1. Static Positioning

Static is the default positioning property in CSS. Elements appear in their normal document flow.

This section uses Static Positioning.

2. Relative Positioning

Relative positioning moves an element from its original position without removing it from the normal document flow.

This box uses position: relative.

3. Absolute Positioning

Absolute positioning places an element relative to its nearest positioned ancestor.
